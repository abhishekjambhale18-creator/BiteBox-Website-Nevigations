> A multi-page static restaurant website for **BiteBox**, built using pure HTML with navigation between Home, Menu, About, and Contact pages.

---

### 📌 Project Overview
This project is a multi-page version of the BiteBox restaurant website.  
It includes four connected pages with a simple navigation system, showcasing restaurant information, offers, contact details, and more.

---

### ✨ Features
- Multi-page website structure
- Navigation links on every page
- Home page with complete restaurant details
- Menu page
- About page
- Contact page
- Special offers and customer notice
- Opening hours and footer

---

### 📄 Pages Included

| Page          | File           | Description                          |
|---------------|----------------|--------------------------------------|
| Home          | `index.html`   | Main page with full restaurant info  |
| Menu          | `menu.html`    | Menu page                            |
| About         | `about.html`   | About Us page                        |
| Contact       | `contact.html` | Contact information page             |
