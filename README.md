> Multi-page restaurant website for BiteBox with Home, Menu, About, and Contact pages connected through navigation.

---

### 📌 Project Overview
This is the third version of the BiteBox website.  
It converts the single-page design into a multi-page website with proper navigation links between Home, Menu, About, and Contact pages.

---

### ✨ Features
- Multi-page website structure
- Navigation bar on every page
- Home page with full restaurant details
- Menu page
- About page
- Contact page
- Special offers and customer notice
- Opening hours and footer

---

### 📄 Pages Included

| Page    | File           | Description                         |
|---------|----------------|-------------------------------------|
| Home    | `index.html`   | Main page with full restaurant info |
| Menu    | `menu.html`    | Menu page                           |
| About   | `about.html`   | About Us page                       |
| Contact | `contact.html` | Contact information page            |

---

### 🛠️ Skills Demonstrated
- Multi-page HTML structure
- Internal page navigation using anchor tags
- Consistent layout across pages
- Organizing content into separate files

---

### 🚀 How to Run
1. Open the repository
2. Open `index.html` in any web browser
3. Use the navigation links to move between pages
